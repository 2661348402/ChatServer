# 开发计划

## 阶段 1：工程骨架和协议层

- CMake 工程
- 消息 ID 枚举
- 消息编码、解码
- 协议单元测试

验收标准：

- `cmake --build build` 通过
- `ctest --test-dir build --output-on-failure` 通过

## 阶段 2：单机网络服务

- 引入或实现 TCP 服务端
- 支持客户端连接、断开
- 支持收到完整协议消息后打印消息 ID 和 body

验收标准：

- 能启动服务端
- 能用客户端发一条登录消息
- 服务端能正确解析消息

## 阶段 3：业务分发层

- `ChatService` 单例
- `unordered_map<int, Handler>` 消息处理器注册
- 登录、注册、私聊处理函数骨架

验收标准：

- 不同 `msg_id` 能进入不同 handler

## 阶段 4：数据模型层

- 用户表
- 好友表
- 离线消息表
- 群组相关表

验收标准：

- 注册能写库
- 登录能查库
- 离线消息能保存和拉取

## 阶段 5：集群能力

- Redis 发布订阅
- 用户连接所在服务器记录
- 跨服务器私聊和群聊

验收标准：

- 启动两个聊天服务器实例
- 用户 A 和用户 B 连接不同服务器也能通信
